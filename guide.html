เครื่องมือแก้ไฟล์ MMAN EDI · ใบขนสินค้าขาเข้า

Change Status → MMAN

เติม POL, SHED NO., รหัสประเทศ และเปลี่ยน STATUS ตู้ ในไฟล์ MMAN ตามรายการ B/L ของงาน ได้ไฟล์ MMAN_EDI.txt ที่ความยาวทุกบรรทัดตรงเดิม พร้อมส่งต่อ

MMAN_*.txt+ SUR.xls→ MMAN_EDI.txt
ทำออนไลน์ (ไม่ต้องติดตั้ง) ดาวน์โหลดโปรแกรม (ZIP) เปิดหน้า GitHub

ทำออนไลน์

เร็วที่สุด ไม่ต้องติดตั้งอะไร ไฟล์ประมวลผลในเบราว์เซอร์เท่านั้น ไม่ถูกอัปโหลดขึ้นเซิร์ฟเวอร์

  1. เปิดหน้า ทำออนไลน์ แล้วเลือกไฟล์ MMAN (.txt)

  2. เลือกรายการ STATUS (.xls / .xlsx / .csv)

  3. เริ่มต้นเก็บ B/L … ถึง B/L (ถ้าต้องการตัดไฟล์)

    เก็บบรรทัด PSKV ไว้ แล้วเก็บเฉพาะ B/L ในช่วงนี้ (รวม sub-B/L …A, …B และบรรทัดตู้) ที่เหลือตัดออก · ว่างช่องเริ่มต้น = ตั้งแต่ B/L แรก · ว่างช่องถึง = ถึงบรรทัดสุดท้าย · ว่างทั้งสองช่อง = ไม่ตัด

  4. ตรวจ SHED NO. ช่องซ้าย = B/L ที่มี Status, ช่องขวา = B/L อื่น

    ค่าเริ่มต้น 0145 / 0122 เปลี่ยนได้ตามงาน · งานที่ไม่มี Status (เช่น LCH) ใส่ SHED NO. ช่องซ้าย แล้วลบช่องขวาให้ว่าง = ใช้ค่าเดียวกันทุก B/L

  5. กด Change ดูสรุปผล แล้วกด ดาวน์โหลด MMAN_EDI.txt

    ถ้าหน้าเว็บยังเป็นแบบเก่า กด Ctrl + F5

ติดตั้งครั้งแรก (โปรแกรมในเครื่อง)

ทำครั้งเดียวต่อเครื่อง ใช้ Windows · ถ้าใช้แบบออนไลน์อย่างเดียว ข้ามส่วนนี้ได้

  1. ติดตั้ง Python 3 จาก python.org/downloads

    หน้าแรกของตัวติดตั้ง ติ๊ก ☑ Add python.exe to PATH ก่อนกด Install Now

  2. ดาวน์โหลดโปรแกรม กดปุ่ม “ดาวน์โหลดโปรแกรม (ZIP)” ด้านบน

    คลิกขวาที่ไฟล์ ZIP → Extract All แล้วเก็บโฟลเดอร์ไว้ที่ไหนก็ได้ เช่น Documents

  3. รันครั้งแรกต้องต่ออินเทอร์เน็ต

    โปรแกรมจะติดตั้งไลบรารีที่ต้องใช้ (pandas, xlrd, openpyxl) ให้เองอัตโนมัติ

ใช้งานทุกครั้ง

  1. วางไฟล์ในโฟลเดอร์ input

    ลบไฟล์งานเก่าออกก่อน แล้ววางไฟล์ MMAN (.txt) และรายการ STATUS (.xls/.xlsx/.csv) อย่างละ 1 ไฟล์ ไฟล์ MMAN_EDI.txt เก่าที่ค้างอยู่ โปรแกรมจะไม่นับเป็นไฟล์ต้นฉบับ

  2. ดับเบิลคลิก run-change-status.bat

  3. พิมพ์ SHED NO. แล้วกด Enter สองครั้ง

    ถามสองค่า: B/L ที่มี Status และ B/L อื่น ถ้ากด Enter ข้าม จะใช้ 0145 และ 0122 · ช่องที่สองพิมพ์ = = ใช้ค่าเดียวกับช่องแรกทุก B/L (งาน LCH)

  4. เปิดผลที่ output\MMAN_EDI.txt

    หน้าจอดำสรุปจำนวน B/L, Status ที่เปลี่ยน และ PG→PX ให้ ถ้ามีบรรทัด WARNING ให้อ่านก่อนใช้ไฟล์

ตัวอย่างประกอบเท่านั้น เลข B/L ย่อไว้

  • B/L No. ใส่เลข B/L หลัก ครอบคลุม sub-B/L ด้วย (…462A, …462B)
  • Status เช่น 9 N, 7 N พิมพ์ช่องว่างกี่ช่องก็ได้ (7 N, 7N) โปรแกรมจัดให้ถูกตำแหน่งเอง · ช่องว่าง = คง Status เดิม
  • POL 5 ตัว เช่น KRPUS, CNSHA

คงเดิมเสมอ

  • ตัวอักษร O หน้า description (ยกเว้น TRANSIT/TRANSHIPMENT)
  • ชื่อของ B/L TRANSIT/TRANSHIPMENT
  • Status ของ B/L ที่ช่อง Status ว่าง
  • B/L ที่ไม่อยู่ในรายการ (แจ้งเตือนให้)
  • ไฟล์ต้นฉบับใน input ไม่ถูกแก้

สรุปผลที่ต้องดูทุกครั้ง

  • จำนวน B/L ที่แก้ ตรงกับจำนวนในรายการ
  • จำนวน SHED 0145 / 0122
  • Status ที่เปลี่ยน และจำนวนบรรทัดตู้
  • B/L ที่เปลี่ยน PG → PX
  • ขนาดไฟล์เท่าต้นฉบับ
